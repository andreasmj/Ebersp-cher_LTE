Sendemotor per plattform
Via Meldingerexpo-sms åpner SMS-appen ferdig utfylt. Standard på iPhone og Android-butikkversjon. Ett trykk i appen + ett i Meldinger.
DirekteEgen Expo-modul (SmsManager + eksakt alarm). Kun Android Pro-APK. Ett trykk med bekreftelse, null på faste dager.
AutomasjoniOS Kortkommandoer «Tidspunkt → Send melding, kjør umiddelbart». Appen genererer oppskrift per plan og slutter selv å minne om den planen.
PåminnelseLokal varsling med «Send nå» kvelden før, og morgen-reserve hvis den ikke ble sendt.
Hva mockupen viser og ikke viser

Viser: alle skjermer i fase 1, alle 8 språk, begge plattformers SMS-flyt, kvelden-før-logikken med 23 t 30-vindu, STOP-advarsel med re-sending, hopp over etter sending, morgen-reserve, status som utløper etter kjøretid, ACCLIM-editor, eksport/slett med bekreftelse, tom tilstand.

Viser ikke: ekte tidsvelgere fra iOS/Android, landvelger med alle land, filvelger ved import, flere kjøretøy (fase 2). Svar fra modulen er eksempeltekster og må kalibreres mot ekte svar fra brukerens enhet.
